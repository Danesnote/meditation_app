# 명상 · 웹 버전

Flutter 명상 앱(저장소 루트)을 브라우저용으로 다시 만든 웹 앱입니다. 같은 기능을 웹 표준 API로 구현했고, 홈 화면에 설치해 앱처럼 쓸 수 있는 PWA입니다.

> 브라우저별 제한과 배포 전 확인할 점은 [CAVEATS.md](CAVEATS.md)에 정리되어 있습니다.

## 기능

화면은 하단 탭 세 개(**명상 · 기록 · 설정**)로 되어 있고, 명상하는 동안에는 탭이 사라집니다.

### 명상 타이머
- **시간 선택**: 1·3·5·10·15·20·30분 또는 1~180분 직접 입력. 마지막으로 고른 시간을 기억합니다.
- **준비 시간**: 시작 전 0~30초 카운트다운.
- **진행 조작**: 시작, 일시정지, 계속, 그만하기, 다시 시작.
- **진행률 원**: 남은 시간 주위의 원이 차오릅니다.
- **정확한 시간 계산**: "끝나는 시각" 기준으로 계산해서, 다른 탭에 다녀와도 어긋나지 않습니다.
- **화면 켜두기**: 명상 중 화면이 꺼지지 않게 합니다.

### 종소리와 배경 소리
- **시작 종 · 중간 종(1~10분 간격, 작게) · 완료 종**
- **배경 소리**: 빗소리, 파도, 화이트 노이즈, 브라운 노이즈. 볼륨 조절, 이음매 없는 반복, 명상 중 즉시 변경.

### 가이드 음성
브라우저의 한국어 음성으로 안내 문장을 읽습니다. 문장이 명상 길이에 맞춰 배치되어 3분이든 30분이든 같은 흐름으로 진행됩니다.

| 가이드 | 내용 |
|---|---|
| 호흡 알아차림 | 숨에 주의를 두고, 생각이 떠오르면 다시 숨으로 돌아오는 연습 |
| 바디 스캔 | 발끝부터 머리까지 몸의 감각을 차례로 느끼기 |
| 자애 명상 | 나, 소중한 사람, 모르는 사람, 어려운 사람, 모든 존재의 평안을 바라기 |

### 호흡 가이드
원이 커지고 작아지며 "들이쉬기 / 멈추기 / 내쉬기"와 남은 초를 보여줍니다.

| 패턴 | 리듬 |
|---|---|
| 편안한 호흡 | 4초 들숨, 6초 날숨 |
| 박스 호흡 | 4초 들숨, 4초 멈춤, 4초 날숨, 4초 멈춤 |
| 4-7-8 호흡 | 4초 들숨, 7초 멈춤, 8초 날숨 |

### 기록과 통계
- **요약**: 연속 일수, 오늘 · 총 명상 시간, 총 횟수, 최장 연속 기록
- **최근 7일 그래프**: 막대에 마우스를 올리거나 키보드로 포커스하면 정확한 값이 나옵니다.
- **최근 기록 목록**: "완료" 또는 "중간에 마침"으로 표시됩니다.

### 알림
- **완료 알림**: 다른 탭을 보고 있을 때 명상이 끝나면 브라우저 알림을 보냅니다.
- **매일 리마인더**: 앱을 열어 둔 동안, 정한 시각이 지나면 하루 한 번 알립니다. 그날 이미 명상했으면 알리지 않습니다.

### 그 밖의 기능
- **다크 모드**: 시스템 / 라이트 / 다크
- **PWA**: 홈 화면에 설치할 수 있고, 소리 파일까지 미리 받아 두어 오프라인에서도 동작하도록 구성했습니다.
- **모바일 대응**: 휴대폰 화면 폭과 노치(safe area)에 맞춘 레이아웃

### Flutter 앱과의 차이

| 기능 | Flutter 앱 | 웹 버전 |
|---|---|---|
| 완료 알림 | 앱이 꺼져 있어도 예약 알림 | 탭이 열려 있는 동안만 |
| 매일 리마인더 | 정한 시각에 예약 알림 | 탭이 열려 있는 동안만 |
| Apple 건강 앱 연동 | iOS 지원 | 없음 (웹에서 쓸 수 있는 API가 없음) |

## 기술 스택

| 구분 | 사용 기술 | 고른 이유 |
|---|---|---|
| UI | [React 19](https://react.dev) + TypeScript | 컴포넌트 단위로 Flutter 화면 구조를 그대로 옮기기 쉬움 |
| 빌드 | [Vite 8](https://vite.dev) | 빠른 개발 서버와 가벼운 프로덕션 번들 |
| 상태 관리 | [Zustand](https://zustand.docs.pmnd.rs) + `persist` | 설정·기록을 localStorage에 자동 저장하는 작은 스토어. 보일러플레이트가 거의 없음 |
| 스타일 | [Tailwind CSS 4](https://tailwindcss.com) | 라이트·다크 색을 CSS 변수 토큰으로 관리하고 유틸리티 클래스로 적용 |
| 소리 | Web Audio API | `<audio loop>`와 달리 배경 소리를 이음매 없이 반복하고, 볼륨을 부드럽게 바꿀 수 있음 |
| 음성 안내 | Web Speech API (`speechSynthesis`) | 별도 서버나 녹음 없이 한국어 가이드 낭독 |
| 화면 켜두기 | Screen Wake Lock API | 명상 중 화면 꺼짐 방지 |
| 알림 | Notifications API + 서비스 워커 | 다른 탭을 보고 있을 때 완료·리마인더 알림 |
| PWA | [vite-plugin-pwa](https://vite-pwa-org.netlify.app) (Workbox) | 설치·오프라인 지원을 설정만으로 구성 |
| 테스트 | [Vitest](https://vitest.dev), Testing Library, jsdom | Vite 설정을 그대로 쓰는 테스트, 가짜 타이머로 시간 조작 |
| 린트 | [oxlint](https://oxc.rs) | Vite 템플릿 기본 린터, 빠름 |
| 사운드 | Python으로 직접 합성한 WAV | Flutter 앱과 같은 파일 (저작권 걱정 없음) |

### 설계

Flutter 앱과 같은 구조입니다.

```
TimerEngine ──이벤트──▶ SessionCoordinator ──▶ AudioPort   (Web Audio, speechSynthesis)
 (시간 계산만)            (부수효과 담당)       ──▶ DevicePort  (Wake Lock, 알림)
                                               ──▶ useHistory  (기록 저장)
```

- **`TimerEngine`**
  - 순수 TypeScript 클래스로, React와 무관하게 시간 계산만 맡습니다.
  - 화면은 `useSyncExternalStore`로 구독하고, 남은 초가 바뀔 때만 다시 그립니다.
- **`SessionCoordinator`**: 타이머 이벤트를 받아 종, 배경 소리, 가이드 음성, 화면 켜두기, 알림, 기록을 처리합니다.
- **`AudioPort` / `DevicePort`**
  - 브라우저 API를 감싼 인터페이스입니다.
  - 테스트에서는 가짜 구현으로 바꿔 끼워서, 실제 소리나 권한 없이 흐름을 검증합니다.
- **소리 재생 권한**: 브라우저는 사용자 클릭 안에서만 소리를 허용합니다. 그래서 시작 버튼을 누를 때 `coordinator.prime()`으로 오디오를 깨우고 알림 권한을 요청합니다.

## 프로젝트 구조

```
src/
  main.tsx                     진입점, 실제 브라우저 서비스 연결
  App.tsx                      하단 탭, 집중 모드, 테마 적용
  core/
    timerEngine.ts             타이머 상태와 시간 계산
    content.ts                 배경 소리 · 가이드 문장 · 호흡 패턴
    stats.ts                   연속 일수 등 통계 계산
  stores/                      설정 · 기록 (Zustand, localStorage 저장)
  services/
    coordinator.ts             타이머 이벤트를 소리 · 알림 · 기록으로 연결
    audio.ts                   Web Audio, 음성 안내
    device.ts                  Wake Lock, 알림
    createServices.ts          타이머와 코디네이터 생성
  components/                  명상 · 기록 · 설정 화면과 공용 UI
  hooks/useApp.ts              서비스 컨텍스트, 타이머 구독
  test/                        테스트 설정과 가짜 서비스
public/
  sounds/                      종소리 · 배경 소리
  icon-*.png, favicon.svg      앱 아이콘
```
