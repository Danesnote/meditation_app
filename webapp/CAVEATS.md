# 주의사항 (웹 버전)

배포하거나 쓰기 전에 알아 둘 점입니다. 기능 소개는 [README](README.md)를 보세요.

## 검증 상태

- **확인한 것**
  - 자동 테스트 32개, 타입 검사, 린트, 프로덕션 빌드를 모두 통과했습니다.
  - Chromium 계열 브라우저에서 1분 명상을 끝까지 실행했습니다. 준비 시간, 호흡 가이드, 빗소리, 종, 한국어 가이드 음성 6문장, 기록 저장이 정상 동작했습니다.
  - 휴대폰 폭(375px)과 라이트·다크 모드에서 레이아웃을 확인했습니다.
- **확인하지 못한 것**
  - **서비스 워커(설치·오프라인)**: 개발에 쓴 내장 브라우저가 서비스 워커 등록을 막아서 확인하지 못했습니다. 일반 Chrome에서 `npm run build && npm run preview`로 연 뒤 설치 버튼과 오프라인 동작을 확인해 주세요.
  - **브라우저 알림**: 권한 팝업과 실제 알림 표시는 확인하지 못했습니다.
  - **Safari · Firefox · 실제 휴대폰**: 확인하지 못했습니다.

## 웹이라서 생기는 제한

| 항목 | 내용 |
|---|---|
| 완료 알림 | 탭이 열려 있어야 합니다. 탭이나 브라우저를 닫으면 알림이 오지 않습니다 (푸시 서버 없이 예약 알림을 보낼 방법이 없음). |
| 매일 리마인더 | 앱을 열어 둔 동안만, 정한 시각이 지나면 하루 한 번 알립니다. 정확한 시각 예약 알림은 아닙니다. |
| 백그라운드 탭 | 브라우저가 숨겨진 탭의 타이머를 느리게 돌릴 수 있습니다. 배경 소리를 틀어 두면 대부분 제때 끝납니다. 시간 계산 자체는 끝나는 시각 기준이라 어긋나지 않습니다. |
| 화면 켜두기 | Screen Wake Lock API를 지원하지 않거나 거부하는 브라우저에서는 동작하지 않습니다. 실패해도 명상은 계속됩니다. |
| 가이드 음성 | 브라우저·OS에 설치된 한국어 음성을 씁니다. 목소리가 환경마다 다르고, 한국어 음성이 없으면 영어 음성으로 읽거나 읽지 않을 수 있습니다. |
| 소리 재생 | 브라우저 정책상 첫 소리는 사용자가 버튼을 누른 뒤에만 납니다. 그래서 시작 버튼을 누를 때 오디오를 준비합니다. |
| iOS Safari | 화면이 잠기면 Safari가 페이지를 멈출 수 있어 종소리·음성이 끊길 수 있습니다. 홈 화면에 추가(PWA)해서 쓰는 것을 권장합니다. |
| 건강 앱 연동 | 웹에서 Apple 건강 앱·Health Connect에 쓸 수 있는 API가 없어 빠져 있습니다. |

## 데이터

- 설정과 기록은 브라우저의 localStorage에만 저장됩니다.
- 브라우저 데이터를 지우거나 시크릿 창을 닫으면 사라지고, 기기·브라우저끼리 동기화되지 않습니다.
- Flutter 앱의 기록과도 공유되지 않습니다.

## 배포

- **HTTPS 필수**: 서비스 워커, 알림, Wake Lock은 HTTPS(또는 localhost)에서만 동작합니다.
- **하위 경로 배포**: GitHub Pages처럼 하위 경로(예: `/meditation_app/`)에 배포할 때는 빌드할 때 `BASE_PATH`를 지정하세요.

  ```bash
  BASE_PATH=/meditation_app/ npm run build
  ```

- **오프라인 캐시 크기**: 소리 파일을 포함해 약 1.8MB를 처음 방문 때 미리 받습니다.
